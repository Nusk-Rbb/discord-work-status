# 使い方

1. アプリを起動し、右上の「**接続**」を押します（起動時に自動接続するオプションもあります）。
2. 左のプリセットを選ぶか、＋ で新規作成します。
3. 詳細・状態・画像などを編集します。右側にプレビューが表示されます。
4. 下部の「**この状態を適用**」で Discord に反映されます。
5. 消したいときは「**プレゼンスを消す**」を押します。

## プリセット

「仕事中」「プログラミング中」「休憩中」など、よく使う状態を登録しておけます。左のリストから選ぶだけで切り替えられるので、作業の切り替わりごとに内容を打ち直す必要はありません。

プリセットごとに次の項目を編集できます。

| 項目 | 説明 |
| --- | --- |
| 詳細 | Rich Presence の 1 行目に表示されるテキスト |
| 状態 | 2 行目に表示されるテキスト |
| 画像 | 大きいアイコンとして表示される画像（[画像の指定方法](./images)を参照） |
| 経過時間 | 「〇〇分経過」の表示を出すかどうか |
| ボタン | プレゼンスの下に表示されるリンクボタン |

## トレイ常駐

ウィンドウを閉じてもアプリはバックグラウンドで動作し続け、プレゼンスは維持されます。完全に終了したい場合はトレイアイコンのメニューから終了してください。

## 設定の自動保存

編集内容は自動的に保存され、次回起動時に前回の状態が復元されます。起動時に自動で Discord へ接続するオプションもあります。
